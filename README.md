# dsh-rest-reminder

DSH (DeepSeek Harness) 的「休息提醒」插件：连续使用一段时间后提醒你起身休息，休息时显示倒计时。

## 功能

- **到点提醒**：连续操作满设定时间（默认 60 分钟），右下角弹出提醒，可「开始休息」或「稍后提醒」。
- **休息倒计时**：圆环倒计时 + 随机小提示，可提前结束或再加 1 分钟；刷新页面后倒计时继续。
- **使用统计**：今日累计使用时长与最近 7 天柱状图（仅统计有键鼠操作的时间）。
- **工作时段**：可限定只在指定时段（支持跨零点）和工作日提醒，时段外只统计不提醒。
- **设置页**：在「设置 → 休息提醒」中配置，保存即生效；中英文跟随 DSH 语言。

## 计时规则

监听 DSH 页面内的鼠标、键盘、滚轮、触摸事件，只记录最后一次操作时间，不读取任何内容。
距最后一次操作不足「空闲判定」时间（默认 5 分钟）才计入使用时长；超过则视为已休息并重新计时。

## 安装

在 DSH 中让助手用插件管理器安装本目录（`install_bundle`，传入本目录绝对路径），然后完全重启 DSH 并硬刷新页面（Ctrl+Shift+R）。

## 数据

全部保存在浏览器 `localStorage`：`rest-reminder:config`、`rest-reminder:state`、`rest-reminder:usage`（保留 30 天）。不上传任何数据。

## 文件

| 文件 | 作用 |
| --- | --- |
| `package.json` | 包声明（`dsh.client`、`exports`） |
| `cordis.patch.yml` | 注册到 profile 的 Cordis 补丁 |
| `index.js` | Host 端入口（空） |
| `client.js` | 浏览器端：计时、浮层、设置页 |
| `locale/` | 插件标题与描述 |
